# 🗣️ 방언 장터

국어 「지역 방언」 개인 디벗 게임. 카드 **앞면(방언 + 작은 글씨 표준어 뜻)은 모두가 보고, 뒷면(어느 지역 말인지)은 주인만** 봅니다. 주인도 카드 아래 띠를 **꾹 누르는 동안만** 보여서, 옆 친구가 화면을 훔쳐봐도 모릅니다(납품 버튼도 몇 장인지 안 알려 줌).

**카드 점수**: 카드마다 1·2·3점(비율 `GAME.points` = 5:3:2, 판마다 무작위로 새로 정하고 지역마다 같은 비율 → 지역끼리 공평). 점수도 뒷면이라 주인만 꾹 눌러 보고 상대에겐 비밀. 팀 점수 = 납품한 우리 지역 카드의 점수 합, 순위는 1인 평균 점수. 정직하게 팔든 속여 팔든 자유, 대신 거래 뒤 **별점**으로 평판이 따라다녀요.

- 칠판: `saturi/board.html` · 학생: `saturi/team.html` (링크만 열면 지역·닉네임 자동, 닉네임은 바꿀 수 있음)
- 카드·설정 고치기: **`saturi/cards.js` 한 파일만**. 큰 방언 풀은 맨 아래 `TSV` 칸에 「지역 ⇥ 앞면 ⇥ 뜻」 표를 그대로 붙여넣기(구글시트·GPT 표 복사). 두 지역에 같은 앞면이 있으면 자동으로 빠짐
- **판마다 다른 방언:** 한 판에 지역마다 16개를 골라 쓰고, 지난 판에 나온 방언은 뒤로 미룸 → 두세 번 해도 새 방언
- **🎁 장날:** 라운드 중 2분마다 모두에게 새 카드 2장(`GAME.restockN`, 아직 안 나온 방언 먼저) → 처음 받은 카드로만 끝나지 않음
- Firebase: 다른 수업 게임과 같은 open-cbd39, `trade/byeokrando` 아래 `d_` 컬렉션 → 규칙 변경 불필요. 학생 화면은 자기 문서만 구독해서 읽기를 줄임

## 거래 (메이플식 거래창)
거래 신청 → 상대 수락(15초) → 둘 다 카드 올리기(상대 카드는 앞면만) → 둘 다 [확인] → 교환 → 받은 카드 뒷면 공개 → 상대에게 별점 1~5
- 확인 뒤에 누구든 카드를 바꾸면 두 사람 확인이 풀림(바꿔치기 방지)
- 같은 지역 친구끼리는 거래 불가 · 한 사람은 한 번에 거래창 하나 · 거절당하면 그 상대에게 10초 동안 다시 신청 못 함 · 거래창에서 90초 동안 아무것도 안 하면 자동으로 닫힘

## 진행 (칠판 버튼)
1. **장터 열기 · 1라운드** (두 번) → 실제 인원에 맞춰 카드가 나눠짐 (한 사람 4~5장, 전부 다른 지역 카드)
2. **🔔 중간 점검** (두 번) → 칠판에 "가장 많이 속은 카드"(별점 2점 이하 거래에서 오간 카드) 5장 → 하나씩 눌러 뒷면 공개
3. **2라운드 시작** → 팀 점수는 비밀(깜깜이)
4. **장터 끝 · 시상** (두 번) → 📋 방언 정리(지역별 정답표, 많이 속은 카드는 빨간 글씨) → 🏆 시상식: 꼴찌 팀부터 공개(팀 안 개인 순위) → 우승 팀 + MVP → 🤝 신용왕(별점 평균 최고, 3명 이상 평가) → 🎁 원 모어 띵 재산왕(최소 납품 2장을 채운 사람 중 남은 카드 최다)

## 점수
주문서·목표 없이 **납품한 우리 지역 방언 카드의 점수 합(카드마다 1·2·3점)**이 점수. 큰 숫자로 보여 주고, 팀 인원이 다를 수 있어서(26명이면 한 팀만 6명) 순위는 **1인 평균**으로 정함. 같으면 많이 모은 팀이 앞.

밸런스 확인(`node saturi/check-balance.mjs`, 인원별 무작위 거래 200회): 10·15·20·24·25·26·27·28·30명 모두 기본 카드로 모든 팀 동시 완성 가능 (26명 기준 필요 거래 최대 약 54건).
