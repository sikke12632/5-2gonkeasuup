# 💬 속뜻 카드

5학년 국어 · 함축 표현 추론 게임 · 4인 1조, 한 사람 한 디벗 · 전자칠판·교사 화면 없음
주소: https://sikke12632.github.io/5-2gonkeasuup/sokttus/

## 수업 전 (교사)

- **방 8개 한 번에 비우기:** 첫 화면의 제목 「속뜻 카드」를 **3초 꾹 누르기** → 확인. 게임 중인 방도 지워지고 아이들 디벗은 첫 화면으로 돌아갑니다.
- 그냥 둬도 한 시간 넘게 아무 일 없던 방은 다음 사람이 들어올 때 저절로 새 방이 됩니다.
- 점검 모드: 주소 뒤에 `?demo=1` (인터넷 없이 한 브라우저의 여러 탭끼리만). 탭 3~4개를 열어 미리 해 볼 수 있어요.

## 아이들 진행

1. 모둠 번호(1~8) + 이름 → 들어가기. 처음 들어온 사람이 방장, 3~5명이면 방장이 [시작].
2. 이야기꾼은 들어온 순서대로 한 번씩. 모두 한 번씩 하면 한 판 끝 → [한 판 더]는 같은 멤버로 다시 섞어서.
3. 새로고침하거나 디벗이 꺼져도 **같은 모둠 번호와 이름**으로 들어오면 자리·손패·점수가 그대로입니다. (같은 모둠에 같은 이름이 둘이면 같은 사람으로 봅니다 → 성까지 쓰게 해 주세요.)
4. 게임이 시작된 뒤에는 새 이름으로 들어올 수 없습니다. 대기실에서 방장이 이름 옆 ×로 잘못 들어온 사람을 내보낼 수 있어요.

## 정해 둔 것

- 힌트: 띄어쓰기 포함 12자. 고른 카드의 금지어는 공백을 지우고 부분 문자열로 검사(한 글자 `웃`도). 걸리면 "카드에 있는 낱말은 쓸 수 없어요"만 보이고 어떤 낱말인지는 안 알려 줍니다.
- 근거: **띄어쓰기를 빼고** 10자 이상이어야 [투표하기]가 눌립니다(빈칸으로 채우기 방지).
- 이야기꾼 화면에는 힌트를 낸 뒤 자기 카드를 표시하지 않습니다(옆에서 엿봐도 정답이 안 보이게).
- 다른 사람의 손패와 공개 전 정답·투표·근거는 그 사람 화면에 오지 않습니다. 디벗은 방 문서(공개 정보)와 **자기 손패 문서만** 구독하고, 정답·카드 주인·투표·맞힌 사람의 근거는 마지막 투표가 들어온 순간에야 방 문서로 옮겨집니다. 틀린 사람의 근거는 방 문서에 아예 쓰이지 않습니다.
- 카드 문장·금지어·속뜻(`note`, 화면에 안 나옴)은 `cards.js`. 받은 그대로입니다.

## Firestore

Firebase 프로젝트는 낱말 경매장과 같은 `open-cbd39`, **Firestore만** 씁니다(Realtime Database 안 씀).

```
auction/s0916/sokttus_rooms/g{1..8}                      방 문서 (공개 정보)
auction/s0916/sokttus_rooms/g{N}/sokttus_players/{pid}    한 사람의 손패·낸 카드·투표·근거
auction/s0916/sokttus_rooms/g{N}/sokttus_secret/deck      남은 덱·버린 카드
```

지금 보안 규칙은 `auction/s0916` 아래만 열려 있고 새 최상위 경로(`/sokttus_rooms`)는 403이라 그 밑에 `sokttus_rooms` 컬렉션을 따로 두었습니다. 경매 게임의 `cards`·`teams`·`state` 등과는 섞이지 않습니다.

최상위로 분리하고 싶으면 콘솔(Firestore › 규칙)의 **지금 규칙 안에** 아래 블록만 더해 게시한 뒤, `store.js` 의 `BASE` 한 줄을 `['sokttus_rooms']` 로 바꾸면 됩니다. (`firebase deploy --only firestore:rules` 는 규칙 전체를 갈아엎으니 쓰지 마세요.)

```
    // 속뜻 카드
    match /sokttus_rooms/{document=**} {
      allow read, write: if true;
    }
```
