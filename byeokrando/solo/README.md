# ⚓ 벽란도 무역항 · 개인 상인판

학생 한 명이 디벗 한 대를 들고 한 나라의 상인이 됩니다. 내 물건으로 거래해서 **우리나라 창고에 납품**하고, 나라 주문서를 가장 많이 채운 팀이 이깁니다.

- 칠판: `byeokrando/solo/board.html` · 학생: `byeokrando/solo/team.html` (칠판의 QR로 접속)
- Firebase 규칙은 바꿀 필요 없음 (모둠판과 같은 `trade/byeokrando` 아래 `p_` 컬렉션 사용)

## 규칙
- 모든 거래는 **고려 상인 ↔ 외국 상인**. 같은 나라끼리, 외국끼리, 고려 상단끼리는 거래 금지
- 구한 물건은 [📦 우리나라에 납품하기]를 눌러야 주문서에 들어감 (주문서에 필요한 만큼만)
- 순위 = 나라 주문서 달성률 → 같으면 먼저 완성한 나라. 주문서 크기는 팀 인원 × 3칸이라 인원이 달라도 공평
- 아라비아 상선: 입항 때 고려 상단 주문서에 (인원 × 1)칸 추가, 2라운드에 금 1 또는 비단 1로 1개씩 선착순

## 스팸 제안 막기
보낸 제안은 한 번에 1개만 · 한 사람이 받는 대기 제안은 최대 3개 · 거절당한 상대에게는 10초 동안 다시 못 보냄 · 답 없는 제안은 30초 뒤 사라짐 · 새 제안 창은 1초 동안 버튼 잠금

## 자동 배정 (26명)
고려 13명(개경 5 · 예성강 4 · 벽란 4) : 외국 13명(송 4 · 거란 3 · 여진 3 · 일본 3). 고려와 외국이 반반이 되도록 번갈아 넣습니다. 준비 화면에서 이름을 눌러 옮길 수 있어요.

## 수업 당일
1. 칠판에서 `solo/board.html` → 학생들이 QR로 들어와 이름 적기 (나라 자동 배정)
2. **[1라운드 시작]** 두 번 → 이때 실제 인원에 맞춰 주문서와 개인 물건이 정해짐
3. **[아라비아 상선 입항]** 두 번 → **[2라운드 시작]**
4. **[무역 끝 · 정리]** 두 번 → 정리 표 → 순위
5. 늦게 온 학생은 그냥 들어오면 칠판이 물건을 조금 나눠 줌. 새 반으로 바꿀 때는 ⚙ 고치기 › 명단 › 모두 지우기

밸런스 확인(`node byeokrando/solo/check-balance.mjs`, 인원별 무작위 거래 200회 흉내): 12·16·20·22·24·25·26·27·28·30명 모두 기본 설정으로 모든 팀 주문서 동시 완성 가능 (26명 기준 필요 거래 최대 약 70건).
