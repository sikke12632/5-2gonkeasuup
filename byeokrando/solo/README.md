# ⚓ 벽란도 무역항 · 개인 상인판

학생 한 명이 디벗 한 대를 들고 한 나라의 상인이 됩니다. 내 물건으로 거래해서 **우리나라 창고에 납품**하고, 나라 주문서를 가장 많이 채운 나라가 무역 승리!

- 칠판: `byeokrando/solo/board.html` · 학생: `byeokrando/solo/team.html` (링크만 열면 나라·별명이 자동으로 정해짐)
- Firebase 규칙은 바꿀 필요 없음 (모둠판과 같은 `trade/byeokrando` 아래 `p_` 컬렉션 사용)

## 규칙
- 거래 가능: **고려 ↔ 외국**, **고려 상단 ↔ 다른 고려 상단**(라이벌). 거래 금지: 같은 팀(같은 상단·같은 나라)끼리, 외국끼리(벽란도를 거쳐야 함)
- 주문서 크기: 외국 팀 인원 × 3칸, 고려 상단 인원 × 4칸(거래 상대가 많아서 난이도↑)
- 구한 물건은 [📦 우리나라에 납품하기]를 눌러야 주문서에 들어감
- 한 사람 **최소 납품 3개**
- 주문서를 100% 채우면 **특별 주문**이 하나씩 끝없이 열림 → 100%를 넘겨 더 많이 채운 나라가 이김 (같으면 먼저 100% 된 나라)
- **무역선 입고**: 라운드 중 2분마다 모든 상인에게 자기 나라 특산품 1개
- **아라비아 상선**: 입항 때 고려 상단 주문서에 (인원 × 1)칸 추가, 2라운드에 금 1 또는 비단 1로 1개씩 선착순
- **깜깜이**: 2라운드부터 칠판의 나라별 진행도를 가림 (버튼으로 켜고 끄기). 학생 디벗에는 우리나라 것만 보임
- **관청 고발**: 2라운드, 한 사람 한 번, 같은 팀(같은 상단·같은 나라) 친구만, 고발한 사람은 비공개
  - 적발(최소 납품을 못 채웠는데 나라에 필요한 물건을 쥐고 있음) → 그 물건 몰수해 나라 창고로, 고발한 사람 납품 +1
  - 무고 → 고발한 사람이 자기 물건 1개를 벌금으로 상대에게. 조사받은 친구는 1분 동안 다시 고발 안 됨

## 스팸 제안 막기
보낸 제안은 한 번에 1개만 · 한 사람이 받는 대기 제안은 최대 3개 · 거절당한 상대에게는 10초 동안 다시 못 보냄 · 답 없는 제안은 30초 뒤 사라짐 · 새 제안 창은 1초 동안 버튼 잠금

## 자동 배정 (26명)
고려 13명(개경 5 · 예성강 4 · 벽란 4) : 외국 13명(송 4 · 거란 3 · 여진 3 · 일본 3). 고려와 외국이 반반이 되도록 번갈아 넣음. 별명은 나라 풍(고려식 / 송 중국식 / 거란 야율·소 씨 / 여진 완안·포찰 씨 / 일본 헤이안풍). 진짜 이름은 원하는 학생만 적음. 준비 화면에서 이름을 눌러 옮기거나 내보낼 수 있음.

## 수업 당일
1. 칠판에서 `solo/board.html` → 칠판에 뜬 주소를 학생들이 디벗으로 열기 (자동 입장)
2. **[1라운드 시작]** 두 번 → 실제 인원에 맞춰 주문서와 개인 물건이 정해짐
3. **[아라비아 상선 입항]** 두 번 → **[2라운드 시작]** (깜깜이 켜짐, 관청 고발 열림)
4. **[무역 끝 · 정리]** 두 번 → 📋 정리 표로 수업 정리 → 🏆 시상식: [다음 공개]로 꼴찌부터 한 나라씩(나라 안 개인 순위 함께) → 우승국 + MVP → **[🎁 원 모어 띵!]** 재산을 가장 많이 축적한 사람(최소 납품을 채운 사람 중 남은 물건이 가장 많은 한 명)
5. 늦게 온 학생은 그냥 들어오면 칠판이 물건을 조금 나눠 줌. 새 반으로 바꿀 때는 ⚙ 고치기 › 명단 › 모두 지우기

밸런스 확인(`node byeokrando/solo/check-balance.mjs`, 인원별 무작위 거래 200회 흉내, 무역선 입고 없이 계산): 12·16·20·22·24·25·26·27·28·30명 모두 기본 설정으로 모든 팀 주문서 동시 완성 가능 (26명 기준 필요 거래 최대 약 70건).
